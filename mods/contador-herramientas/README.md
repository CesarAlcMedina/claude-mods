# contador-herramientas

Mod para Claude Code que cuenta cuántas herramientas (Bash, Edit, Read, etc.) ha usado Claude durante la sesión y muestra el total en la barra de estado, por ejemplo "🔧 5 herramientas".

Uso: el contador arranca en cero al abrir la sesión y sube con cada llamada. Escribe `/reiniciar` para ponerlo a cero en cualquier momento. No necesita configuración.
