# claude-mods

Mods personales para Claude Code.

## Instalar

En la app de escritorio: pulsa **+** junto al cuadro de texto → **Plugins** → **Add marketplace** con `CesarAlcMedina/claude-mods` → **Add plugin**.

En la terminal:

```
/plugin install contador-herramientas --marketplace CesarAlcMedina/claude-mods
```

## Mods

- **contador-herramientas**: muestra cuántas herramientas ha usado Claude en la sesión. Comandos `/contador` y `/reiniciar`.
